# Audioría Digital — Cotizador

Cotizador en línea (marca **Impulso Digital**) para el servicio de auditoría y
estrategia digital de comunicación política.

- `index.html`: página autocontenida (HTML/CSS/JS, sin build ni dependencias
  de servidor) con el checklist de 22 categorías, cálculo de subtotal/total
  en vivo, descuento (%) y exportación de la cotización a PDF, `.txt` o
  copiado al portapapeles.

## Publicar con GitHub Pages

1. Ve a **Settings → Pages** en este repositorio.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/ (root)`.
4. Guarda — GitHub publicará `index.html` como la página principal del sitio
   (la URL aparecerá en esa misma pantalla, normalmente en 1–2 minutos).

## Origen de los datos

Los precios y el detalle de cada categoría provienen de
`Cotizador_Auditoria_Digital_Politica.xlsx` (22 macro-categorías, 275 puntos
de análisis).
